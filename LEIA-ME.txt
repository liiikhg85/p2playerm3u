P2 PLAYER M3U CACHE V2

SUBSTITUIR NO GITHUB
- server.js
- package.json
- render.yaml pode permanecer igual; este arquivo também está incluído.

COMO TESTAR

1. Faça commit dos arquivos.
2. Aguarde o Render concluir o deploy.
3. Abra:
   https://p2player-m3u.onrender.com/status?token=SEU_ACCESS_TOKEN

Durante o download:
   "cacheReady": false
   "updating": true

Quando terminar:
   "cacheReady": true
   "updating": false
   "cacheBytes": número maior que zero
   "cacheUpdatedAt": data/hora

4. SOMENTE depois de cacheReady=true, teste:
   https://p2player-m3u.onrender.com/playlist?token=SEU_ACCESS_TOKEN

A playlist é baixada integralmente antes de entrar no cache. Enquanto uma
atualização futura acontece, a versão anterior continua disponível.

OBSERVAÇÃO DO PLANO FREE
O cache fica na memória da instância. Se o Render desligar a instância por
inatividade, o cache é perdido e será reconstruído quando o serviço acordar.
